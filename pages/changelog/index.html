Changelog

Every update, improvement, and fix — all in one place.

v1.3.1 — Multi-language system & publication prep

  • Multi-language translation system in the popup:
    • Translation helper (languages.js) with Spanish and English support.
    • Decoupled error messages: background sends error codes (errorCode) and the popup translates them.
    • Automatic browser language detection on popup load (languageSettings.js).
    • Visual toggle with inline SVG flags (Spain / UK) to switch languages.
    • Language preference persistence via chrome.storage.local.
  • Added storage permission to manifest.json for saving language preference.
  • Prepared materials for Chrome Web Store publication:
    • Short and long descriptions.
    • Privacy policy.
    • Permissions justification.
  • Reorganized popup scripts into js/ folder (popup.js, languages.js, languageSettings.js).
  • Updated extension build to copy js/ folder to dist/.
  • Updated general and extension documentation.

v1.3.0 — Stable release with visual redesign & distribution prep

  • Published stable version 1.3.0 on GitHub.
  • Includes all features from the 1.2.x series:
    • Popup with advanced options (format, compact, roles).
    • Cyberpunk redesign with CSS token system.
    • Automated ZIP build.
    • Final icons in all sizes.
    • Progress indicator and UX improvements.
  • Updated documentation and preparation for Chrome Web Store publication.

v1.2.4 — Visual redesign & UX improvements in the popup

  • Added contextual header to the popup showing the conversation provider (Exporting from ChatGPT), ready for future models.
  • Implemented animated CSS spinner as a progress indicator during export, replacing the "Processing..." text.
  • Disabled the Export button during processing to prevent multiple clicks.
  • Improved the error message when no conversation is captured, including the provider name.
  • Added dynamic extension version in the popup footer, retrieved from chrome.runtime.getManifest().
  • Applied a complete cyberpunk redesign to the popup:
    • Dark background with radial gradient.
    • Glassmorphism effects on surfaces.
    • Switch and radio buttons with physical hardware look (raised/pressed).
    • Native select styled with the new appearance: base-select API.
  • Implemented a CSS token system (design variables) with color palette derived from the extension icon.
  • Modularized popup CSS by responsibility into independent files (variables.css, base.css, selector.css, options.css, button.css, footer.css).
  • Fixed compact mode tests that expected quote formatting (>), which was removed in v1.2.2.
  • Updated general and extension documentation.

v1.2.3 — Compact mode & role filters in the extension

  • Added advanced options to the extension popup:
    • Checkbox for compact mode.
    • Radio buttons to filter by role (all, user, assistant).
  • Markdown-specific options hidden when JSON is selected.
  • Extracted popup CSS to an independent file (popup.css).
  • Updated background.js to propagate compact and roleFilter to the pipeline.
  • Updated extension build to include popup.css.
  • Updated general and extension documentation.

v1.2.2 — Role filter & compact mode improvements in CLI

  • Extended filter.js to accept an optional targetRole parameter to filter messages by user, assistant, or keep all.
  • Integrated role filter into pipeline.js via config.roleFilter.
  • Added --role / -r option to CLI with validation in validator.js.
  • Improved compact mode in the Markdown generator:
    • Now preserves horizontal rules (---) and lists (- , 1. ) that require specific spacing in Markdown.
    • Implemented a placeholder technique (protect → process → restore) to handle edge cases like list-to-paragraph transitions.
  • Added automated tests for role filtering.
  • Updated general documentation.
