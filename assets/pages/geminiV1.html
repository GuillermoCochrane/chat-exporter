Features

Designed for developers and power users who need their data clean and accessible.

Markdown

Clean documents ready for Obsidian, Notion or GitHub. Headers, code blocks, and formatting preserved.

JSON

Keep the original structure intact for parsing, scripting, or archiving.

Role Filters

Export only User prompts, Assistant replies, or the complete conversation.

Compact Mode

Cleaner Markdown with reduced spacing for dense technical conversations.

Privacy First

Your data is yours. The architecture guarantees zero data leakage.

100% Local

Everything runs in your browser. No external APIs. No cloud processing.

No Tracking

No analytics, no telemetry, no accounts required to use the exporter.
