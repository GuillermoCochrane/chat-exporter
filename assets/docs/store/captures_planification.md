Las capturas son muchísimo más importantes de lo que parecen. Mucha gente decide instalar una extensión **solo mirando las screenshots**.

Yo las planearía como una pequeña historia, no como imágenes sueltas.

Yo incluso haría **todas con el mismo estilo**, como si fueran diapositivas de una presentación:

* mismo fondo oscuro,
* mismo encabezado,
* misma tipografía,
* mismo color de acento (cian),
* mismo margen.

Que al pasar de una a otra parezca una presentación profesional, no seis capturas improvisadas.

Con el popup cyberpunk que ya hiciste, podés lograr una ficha de la Chrome Web Store que dé una impresión muy cuidada desde el primer vistazo.

---

Jajaja sí, esos dos son los más difíciles porque no muestran una función, sino una promesa.

Yo no intentaría representar literalmente "Privacy" y "Open Source". En cambio, haría algo visual que transmita esa idea.

## 5. Privacy First

La captura podría ser del popup de la extensión, mostrando el estado listo para exportar.

Y al costado (en la imagen promocional, no en el popup) agregar cuatro bullets grandes:

```
✓ Local processing

✓ No cloud

✓ No telemetry

✓ No tracking
```

O incluso más corto:

```
Privacy First

• Local processing
• No data collection
• No cloud
• No tracking
```

Eso comunica mucho más que una captura de código.

---

## 6. Open Source

Acá sí mostraría GitHub.

No el README.

La portada del repositorio.

Con:

* cantidad de estrellas (aunque al principio sean pocas)
* licencia MIT
* descripción
* árbol del proyecto

Y al costado algo como:

```
Open Source

MIT License

View the source
Contribute
Fork
Audit the code
```

La gente identifica inmediatamente GitHub.

## Incluso iría un paso más

Como vos diseñaste los íconos con una estética cyberpunk bastante cuidada, haría TODAS las capturas sobre el mismo fondo.

Algo tipo:

* fondo oscuro
* un degradado violeta/azul
* una tarjeta con la captura
* un título enorme

Por ejemplo:

> **Privacy First**

debajo

> Everything happens on your device.

Y recién abajo los bullets.

Así todas las imágenes parecen parte del mismo producto, no simples screenshots pegados.

La Chrome Web Store está llena de extensiones que suben seis capturas sin coherencia visual. Si las tuyas parecen una pequeña presentación de producto, ya se sienten más profesionales incluso antes de que alguien las instale.
